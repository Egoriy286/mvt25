Готовый расчёт с выполненными ячейками и графиками: **[laba1.ipynb](laba1.ipynb)**.
Тот же расчёт в виде скрипта: **[laba1.py](laba1.py)**.

Дополнительное требование преподавателя выполнено для двух сеток:
**80×40 и 160×80**. Решение на сетке 160×80 принято за точное при оценке
погрешности решения на сетке 80×40.

## Постановка и метод

В прямоугольнике Ω = (0, 200) × (0, 100) м решается уравнение

\[
B(p)\frac{\partial p}{\partial t}-\operatorname{div}(C(p)\nabla p)=0,
\]

\[
B(p)=\rho_0[1+c_f(p-p_0)]\phi c_t,\qquad
C(p)=\rho_0[1+c_f(p-p_0)]\frac{k}{\mu}.
\]

Начальное давление — 10 МПа. На верхней половине левой стороны
(x = 0, 50 ≤ y ≤ 100 м) при t > 0 поддерживается 18 МПа.
На остальных сторонах поток равен нулю. Объёмных источников нет.

| Параметр | Значение |
|---|---:|
| Проницаемость k | 5·10⁻¹⁴ м² |
| Вязкость μ | 0,001 Па·с |
| Пористость φ | 0,2 |
| Начальная плотность ρ₀ | 900 кг/м³ |
| Общая сжимаемость cₜ | 2·10⁻⁹ Па⁻¹ |
| Сжимаемость жидкости c_f | 5·10⁻⁶ Па⁻¹ |
| Конечное время T | 24 ч |
| Шаг по времени τ | 1 ч на обеих сетках |

По пространству используются треугольные элементы P₁, по времени — неявная
схема с коэффициентами B и C с предыдущего слоя:

\[
\int_\Omega B(p^n)p^{n+1}v\,dx+
\tau\int_\Omega C(p^n)\nabla p^{n+1}\cdot\nabla v\,dx
=\int_\Omega B(p^n)p^nv\,dx.
\]

Диффузионный член имеет знак **плюс**, следующий из исходного уравнения.
В формулах (9.7)–(9.8) исходного задания опечатка в знаке.

## Вычисление погрешности

Обозначим крупносеточное решение через p_h, мелкосеточное через p_ref.
Крупносеточная функция интерполируется в пространство P₁ мелкой сетки.
Сетки вложены и имеют одинаковое направление диагоналей, поэтому такой
перенос точно представляет исходную кусочно-линейную функцию.

\[
E_{L^2}=\left(\int_\Omega(Ip_h-p_{\rm ref})^2\,dx\,dy\right)^{1/2},
\qquad E_{\rm rel}=\frac{E_{L^2}}{\|p_{\rm ref}\|_{L^2(\Omega)}}.
\]

Дополнительно вычисляются среднеквадратичная ошибка
E_RMS = E_L² / √|Ω| и максимальная ошибка E_∞ = max |Ip_h − p_ref|.
Площадь |Ω| = 20 000 м². Квадрат разности интегрируется на мелкой сетке
квадратурой степени 2. Максимум модуля кусочно-линейной разности достигается
в одном из узлов.

## Результаты

| Сетка | h_x = h_y, м | Узлов | Треугольников | Среднее давление при T = 24 ч, МПа |
|---|---:|---:|---:|---:|
| 80×40 | 2,5 | 3321 | 6400 | 15,397014 |
| 160×80 (эталон) | 1,25 | 13041 | 25600 | 15,387614 |

Погрешность решения 80×40 относительно 160×80:

| t, ч | E_L², Па·м | E_rel, % | E_RMS, МПа | E_∞, МПа |
|---:|---:|---:|---:|---:|
| 1 | 1,752786·10⁶ | 0,117074 | 0,012394 | 0,526275 |
| 6 | 1,615018·10⁶ | 0,087838 | 0,011420 | 0,128723 |
| 12 | 1,520478·10⁶ | 0,075772 | 0,010751 | 0,094432 |
| 24 | **1,375670·10⁶** | **0,063052** | **0,009727** | **0,065692** |

Через сутки RMS составляет около **9,73 кПа**, максимальное расхождение —
**65,69 кПа**. Относительная норма рассчитана по полному давлению эталона.
Нулевые нормы в строке эталона в `summary.csv` означают сравнение с самим
собой. Истинная погрешность мелкой сетки этим не определяется.
Сравнение оценивает влияние пространственной сетки при τ = 1 ч;
погрешность по времени и порядок сходимости отдельно не исследуются.

Проверены диапазон давления 10–18 МПа на каждом слое и баланс дискретной
схемы. Максимальная относительная ошибка баланса: 2,40·10⁻¹³ для сетки
80×40 и 4,96·10⁻¹² для сетки 160×80.

Коэффициент c_f взят буквально из задания: c_f·Δp = 40.
При этих данных предположение о малом изменении плотности не выполняется;
расчёт сохраняет исходные учебные параметры.
