# Практическая работа 1. Фильтрация

Открыть **[laba1.ipynb](laba1.ipynb)** или **[laba1.py](laba1.py)**.

В коде по порядку: параметры → `RectangleMesh` → `SubDomain` и `DirichletBC` → вариационная форма → цикл по времени → графики и вывод.

Прямоугольник 200×100 м, начальное давление 10 МПа, 18 МПа на верхней половине левого края, нулевой поток на остальных сторонах. 24 шага по часу, сетка 40×20.

[Давление](results/filtration.png) · [Таблица по времени](results/history.csv). В ParaView открыть `results/pressure.pvd`.

В слабой форме исправлен знак диффузии по исходному PDE: нужен плюс. Коэффициент c_f=5·10⁻⁶ взят из PDF буквально: c_fΔp=40, поэтому режим малого изменения плотности здесь не выполняется.

Запуск из папки работы в контейнере: `python3 laba1.py`. [Исходные PDF](materials/README.md).
