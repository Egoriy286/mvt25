## Постановка, соответствующая референсному коду

\[
\operatorname{div}u=0,\qquad u=-\frac{k}{\mu}\nabla p,
\qquad p\big|_{\Gamma_1}=0,
\qquad p\big|_{\Gamma_{2,L}}=p\big|_{\Gamma_{2,R}}=1.
\]

Область — прямоугольник [0, 2] × [0, 1] с двумя вырезанными скважинами
радиуса 0,02. Центры (0,5; 0,5) и (1,5; 0,5) выбраны по рисунку задания.
Параметры референса: k = μ = 1, давление в обеих скважинах p_w = 1.
Величины приведены в модельных единицах.

**В основном расчёте воспроизводится именно код и картина течения из PDF.**
В коде внешний нормальный поток не ограничен и отсутствует внешний
граничный интеграл. Для данной смешанной формы это означает естественное
условие p = 0 на внешнем контуре. Оно отличается от записанного в тексте
условия (1.3) u·n = 0. При закрытом внешнем контуре и одинаковом p_w = 1
решение было бы p ≡ 1, u ≡ 0. В текущем расчёте внешний контур открыт:
жидкость поступает из обеих скважин и выходит через границу прямоугольника.
Разные давления между скважинами не вводились.

## Смешанная вариационная форма

Скорость принадлежит H(div, Ω), давление — L²(Ω). Использована устойчивая
пара RT₀–DG₀: `FiniteElement('RT', triangle, 1)` в нумерации DOLFIN и
`FiniteElement('DG', triangle, 0)`.

\[
a((u,p),(v,q))=\int_\Omega\frac{\mu}{k}u\cdot v\,dx
-\int_\Omega p\,\operatorname{div}v\,dx
+\int_\Omega q\,\operatorname{div}u\,dx,
\]

\[
\ell(v,q)=-\sum_{i=L,R}p_{w,i}\int_{\Gamma_{2,i}}v\cdot n\,ds
-p_{\rm out}\int_{\Gamma_1}v\cdot n\,ds.
\]

При p_out = 0 последний интеграл равен нулю — как в референсе.
`DirichletBC` для скорости не задаётся. Седловая линейная система решается
прямым методом UMFPACK. Давления меняются в начале `.py` или notebook:
`P_W = (1., 1.)`, `P_OUTER = 0.`.

## Сетки через mesh.geo и dolfin-convert

Gmsh читает `mesh.geo`, строит треугольники и сохраняет MSH 2.2.
Физические метки: 1 — внешний контур, 2 — левая скважина,
3 — правая скважина, 10 — расчётная поверхность.

На исходной сетке каждая окружность аппроксимирована 64 отрезками.
Для эталона Gmsh повторно читает MSH без CAD-геометрии и делит каждый
треугольник на четыре. Обе вложенные сетки описывают одну и ту же
многоугольную область; геометрия скважин при сравнении не меняется.

Для обеих сеток выполняется:

```bash
dolfin-convert mesh.msh mesh.xml
```

Команда запускается в `results/coarse/` и `results/reference/`.
DOLFIN читает `mesh.xml` и физические метки из `mesh_facet_region.xml`.

## Нормы погрешности

За эталон принято решение на мелкой сетке:

\[
E_p=\|p_H-p_h\|_{L^2(\Omega)},\qquad
E_u=\left(\int_\Omega|u_H-u_h|^2\,dx\right)^{1/2}.
\]

Относительные нормы: E_p / ‖p_h‖_L² и E_u / ‖u_h‖_L².
RMS — соответствующая абсолютная норма, делённая на √|Ω|.

| Поле | Абсолютная L²-норма | Относительная L²-норма | RMS |
|---|---:|---:|---:|
| Давление | 0,01215321 | **3,73682%** | 0,00859901 |
| Скорость | 0,12453922 | **6,53368%** | 0,08811782 |

DG₀-давления сравниваются на мелких треугольниках с точным учётом их
площадей. Для скорости применяется точная квадратура степени 2 с тремя
внутренними точками. Узловая интерполяция разрывных полей не используется.
Собственная погрешность эталона относительно непрерывной задачи неизвестна;
по двум сеткам порядок сходимости независимо не определяется.

## Проверки решения

Нормаль направлена наружу из расчётной области. Отрицательный поток
на скважине означает поступление жидкости в пласт.

| Величина | Грубая сетка | Эталонная сетка |
|---|---:|---:|
| Минимальное давление в ячейках | 0,001925 | 0,000500 |
| Максимальное давление в ячейках | 0,993229 | 0,996614 |
| Поток через внешний контур | 3,617748 | 3,633258 |
| Поток через левую скважину | −1,808476 | −1,816528 |
| Поток через правую скважину | −1,809272 | −1,816731 |
| Относительная ошибка баланса потоков | 1,11·10⁻¹⁴ | 1,46·10⁻¹³ |
| Относительная ошибка энергетического баланса | 2,31·10⁻¹⁴ | 2,22·10⁻¹³ |
| ‖div u‖_L² | 3,71·10⁻¹¹ | 7,43·10⁻¹⁰ |
| Относительная невязка линейной системы | 3,27·10⁻¹⁴ | 1,97·10⁻¹³ |

Внешний отток равен суммарной подаче из скважин. Энергетический баланс:
∫(μ/k)|u|² dx = −∫p_D u·n ds. Максимальная скорость по значениям в центрах
ячеек эталона — около **14,779**. Давление DG₀ хранится в ячейках, поэтому
его ячеечные экстремумы не обязаны совпадать с граничными значениями 0 и 1.
