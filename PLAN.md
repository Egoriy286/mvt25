# План работ

Для каждой работы: прочитать условие → задать параметры → записать формулы → реализовать метод → построить графики → проверить результат → написать вывод.

| Работа | Сделано |
|---|---|
| Градиентный спуск | Ряд exp(x), обычный SGD, сравнение весов и функций |
| Transfinite 2D | Геометрия, 100 SubMesh, метка границ 1 |
| Transfinite 3D | Геометрия, 1000 SubMesh, метка границ 1 |
| DOLFIN и MPI | Пуассон, 103041 вершина, замеры на 1/2/4/6/8/12/16 процессах |
| Газовая динамика | Твой пример XYGEF, прогонка, Ньютон, поля и анимация |
| Теплопроводность | Три слоя, неявная схема, температура и потоки |
| Фильтрация | Неявная МКЭ-схема, давление за 24 часа |

Основные файлы перечислены в [README](README.md). Код расчёта, формулы и выводы находятся в самих notebooks; команды для отдельных `.py` — в README соответствующей работы.
