# Задание 4. Треугольная сетка 2D

Основные файлы: **[lr4.py](lr4.py)** и **[mesh.geo](mesh.geo)**.

Порядок расчёта:

1. В `mesh.geo` два цикла создают квадрат 1×1 из `n*n` блоков командой `Rectangle`. `Coherence` объединяет совпадающие точки и линии соседних блоков.
2. Gmsh сразу строит треугольники. Размер задаётся через `h = 1/(n*fine)`. Исходная сетка сохраняется в `mesh.msh`, для DOLFIN она записывается в `mesh.xml`.
3. Класс `Square(SubDomain)` задаёт каждый крупный квадрат по координатам. `SubMesh(mesh, domain)` выделяет соответствующую подсетку.
4. Класс `Boundary(SubDomain)` отмечает границы подсеток меткой 1. В списке `submeshes` хранятся пары `(подсетка, метки границ)`.
5. Каждая подсетка сохраняется отдельно в `results/submeshes_2/submesh_0.pvd`, `submesh_1.pvd` и т. д.

Параметры `n` и `fine` меняются в `mesh.geo`. Значение `n` Python читает оттуда же; количество подсеток равно `n*n`. При `n = 10` получается 100 подсеток.

Визуализация показывает мелкую треугольную сетку чёрным цветом, границы крупных блоков — синим. [Рисунок сетки](results/mesh.png) сохраняется и отображается через `plt.show()`.

Разбиение всей области также сохраняется в `results/blocks.pvd` для ParaView.
