# Задание 5. Тетраэдральная сетка 3D

Основные файлы: **[lr5.py](lr5.py)** и **[mesh.geo](mesh.geo)**.

Порядок расчёта:

1. В `mesh.geo` три цикла создают куб 1×1×1 из `n**3` блоков командой `Box`. `Coherence` объединяет общие грани соседних блоков.
2. Gmsh сразу строит тетраэдры. Размер задаётся через `h = 1/(n*fine)`. Исходная сетка сохраняется в `mesh.msh`, для DOLFIN она записывается в `mesh.xml`.
3. Крупные блоки выбираются по координатам центров элементов, без физических меток Gmsh.
4. `SubMesh` выделяет подсетки, `DomainBoundary().mark(facets, 1)` отмечает их границы. В списке `submeshes` хранятся пары `(подсетка, метки границ)`.

Параметры `n` и `fine` меняются в `mesh.geo`. Значение `n` Python читает оттуда же; при `n = 10` получается 1000 подсеток.

Визуализация показывает треугольники на наружной поверхности куба чёрным цветом, границы крупных блоков — синим. [Рисунок сетки](results/mesh.png) сохраняется и отображается через `plt.show()`.

Разбиение всей области также сохраняется в `results/blocks.pvd` для ParaView.
