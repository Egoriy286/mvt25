# Лабораторная 6. Метод характеристик

[Ноутбук](laba6.ipynb) · [Скрипт](laba6.py)

В варианте 6-1 схема Самарского и Попова и МКЭ сопоставлены с решением по характеристикам. [Разбор и запуск](laba6-1.md)

Начальный профиль для обеих задач $u_0(x)=e^{-ax^2}$. Продолжение гауссианы на всю прямую задаёт значения на входе $x=0$.

- **Линейный перенос** $u_t+e^{-bt^2}u_x=0$. Все характеристики сдвигаются на $S(t)=\int_0^t e^{-bs^2}\,ds$. [Графики](results/transport.png)
- **Уравнение Хопфа** $u_t+u\,u_x=0$. Характеристика из $\xi$ идёт со скоростью $u_0(\xi)$. Профили строятся до $\min(T,t_*)$, где $t_*=\sqrt{e/(2a)}$ — момент появления вертикальной касательной. [Графики](results/hopf.png)

## Запуск

Открой ноутбук и выполни все ячейки или запусти скрипт из корня проекта.

```bash
.venv/bin/python AppliedMathematics/laba6/laba6.py
```

Параметры в начале кода. Нужны NumPy и Matplotlib. Оба PNG сохраняются в `results/`.
