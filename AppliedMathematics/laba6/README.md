# Лабораторная 6. Уравнение переноса методом характеристик

[Notebook](laba6.ipynb) · [Python](laba6.py) · [Графики](results/transport.png)

Постановка с фотографии `IMG_2528.HEIC`, присланной 06.11.2026:

$$
u_t+e^{-bt^2}u_x=0,\qquad u(x,0)=e^{-ax^2},\qquad 0<x<\ell,\quad 0<t\le T.
$$

На характеристиках $dx/dt=e^{-bt^2}$, $du/dt=0$. Обозначим

$$
S(t)=\int_0^t e^{-bs^2}\,ds=\frac{\sqrt\pi}{2\sqrt b}\operatorname{erf}(\sqrt b\,t),\quad b>0.
$$

Тогда $x_0=x-S(t)$ и $u(x,t)=\exp[-a(x-S(t))^2]$. При $b=0$ используется $S(t)=t$.
В случае переменной скорости сдвиг нельзя заменять на $t v(t)$ или просто $v(t)$.

## Граничное условие

На фото не задано условие при $x=0$. Для решения на всём конечном отрезке оно необходимо, поскольку скорость положительна. В реализации принято продолжение начальной гауссианы на всю прямую, которое задаёт $u(0,t)=\exp[-aS(t)^2]$. Это допущение реализации, а не дополнительное условие с фото.

Если задано другое условие $u(0,t)=\mu(t)$, то при $x<S(t)$ решение равно $\mu(t_*)$, где $S(t_*)=S(t)-x$. При $x\ge S(t)$ остаётся $u_0(x-S(t))$. В углу требуется $\mu(0)=u_0(0)=1$. На выходной границе $x=\ell$ условие не задаётся.

## Запуск

Из корня проекта:

```bash
.venv/bin/python AppliedMathematics/laba6/laba6.py
```

Либо открой `laba6.ipynb` и выполни все ячейки. Нужны только NumPy и Matplotlib; функция `erf` входит в стандартную библиотеку Python. FEniCS и SciPy не требуются.

Параметры меняются в первой кодовой ячейке: `a=25`, `b=1`, `ell=2`, `T=2`, `N=M=200`. Численные значения на фото не указаны, поэтому это учебный пример. Массив `U[j, i]` хранит $u(x_i,t_j)$.

## Результаты и проверка

- `results/transport.png` — профили в разные моменты времени, карта решения и характеристики.
- `results/transport.npz` — полное решение, сетки, сдвиг, скорость и параметры.
- `results/profiles.csv` — пять профилей решения.
- `results/motion.csv` — скорость, сдвиг и значение на левой границе во времени.

Код проверяет начальное и выбранное граничное условия, диапазон значений и невязку $u_t+v(t)u_x$ через центральные разности. Для параметров примера $S(2)=0.88208139$.

Это вычисление точной формулы методом характеристик в узлах сетки; пошаговая разностная схема и ограничение CFL не используются. Разностная невязка служит проверкой формулы, а не оценкой ошибки численного интегрирования уравнения.
