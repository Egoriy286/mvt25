# Лабораторная работа 2. Газовая динамика

Идеальный газ на отрезке $[0,1]$ с неподвижными непроницаемыми стенками. В начальный момент $u_0=0$, $\rho_0=1$ и $p_0(x)=1+0.1\exp[-((x-0.5)/0.12)^2]$. Показатель адиабаты $\gamma=1.4$. В обоих расчётах $N=200$ интервалов, $M=80$ шагов до $T=0.12$.

## Конечно-разностная схема в переменных Лагранжа

Массовая координата $s$ помечает частицы газа, а $x(s,t)$ задаёт их положение. При единичной начальной плотности $x(s,0)=s$. Удельный объём $V=1/\rho$, удельная внутренняя энергия $E$. Уравнения имеют вид

$$
u_t=-p_s,\qquad x_t=u,\qquad V_t=u_s,\qquad E_t=-p u_s,\qquad p=(\gamma-1)E/V.
$$

На равномерной сетке по $s$ с шагом $h=1/N$ координата $X_i$ и скорость $U_i$ хранятся в узлах. Величины $V_i,E_i,P_i$ относятся к ячейке между узлами $i$ и $i+1$. Первый индекс массивов в коде задаёт слой времени. Обозначим $\overline{A}=(A^{n+1}+A^n)/2$, $\tau=T/M$. Схема вычисляет разность давлений между ячейками в узле, а разность скоростей между узлами в ячейке.

$$
\begin{aligned}
U_i^{n+1}-U_i^n&=-\frac{\tau}{h}(\overline P_i-\overline P_{i-1}), &
X_i^{n+1}-X_i^n&=\tau\overline U_i,\\
\Delta V_i&=\frac{\tau}{h}(\overline U_{i+1}-\overline U_i), &
E_i^{n+1}-E_i^n&=-\overline P_i\,\Delta V_i.
\end{aligned}
$$

Скорости $U_0=U_N=0$ заданы на обоих слоях. В `laba2.py` и `compressed.py` вектор `v` начинается с $U^n$. На каждой итерации `np.diff(v)` вместе с разностями со старого слоя даёт `dV`. Подстановка уравнения состояния в баланс внутренней энергии позволяет выразить новое давление `p1` через `dV`.

$$
p_i^{n+1}=
\frac{(\gamma-1)(E_i^n-P_i^n\Delta V_i/2)}{V_i^n+(\gamma+1)\Delta V_i/2}.
$$

Невязка `F` — левая часть уравнения скорости после переноса разности давлений влево. Каждая её строка зависит от трёх соседних скоростей через две смежные ячейки. Для `dp` $=\partial p^{n+1}/\partial\Delta V$ и $\mu=\tau^2/(4h^2)$ диагональ якобиана равна $1-\mu(\mathrm{dp}_{i-1}+\mathrm{dp}_i)$, соседние коэффициенты равны $\mu\,\mathrm{dp}_{i-1}$ и $\mu\,\mathrm{dp}_i$. Прогонка решает $J\,\delta v=-F$, после чего `v[1:-1]` обновляется. При $\max|F|<10^{-12}$ код сохраняет новый слой всех пяти массивов.

Дискретная работа давления со знаком минус в уравнении для $E$ и со знаком плюс в балансе кинетической энергии сокращается при суммировании по ячейкам. Стенки работы не совершают, поэтому сохраняется

$$
H=h\sum_i\left(E_i+\frac{U_i^2+U_{i+1}^2}{4}\right).
$$

Код также проверяет $V_i=(X_{i+1}-X_i)/h$ и положительность плотности и давления. [Ноутбук](laba2.ipynb) · [Скрипт](laba2.py) · [Компактный скрипт](compressed.py) · [Графики](results/gas.png) · [Анимация](results/gas.gif)

## Метод конечных элементов на подвижной сетке (ALE)

В `laba2-ale.py` узлы двигаются со скоростью $w_i=u_i/2$, которая равна нулю на стенках. Газ переносится через подвижные границы элементов с относительной скоростью $u-w$. Вектор $Q$ содержит плотность, импульс и полную энергию на единицу объёма. Поток в физических координатах и уравнение состояния имеют вид

$$
Q=(\rho,\rho u,\mathcal E)^{\mathsf T},\quad
F(Q)=uQ+(0,p,pu)^{\mathsf T},\qquad
p=(\gamma-1)(\mathcal E-\rho u^2/2).
$$

Аппроксимируем $Q$ непрерывными линейными функциями по элементам $[X_i,X_{i+1}]$. Тестовая функция $\varphi_i$ движется вместе с сеткой и удовлетворяет $(\varphi_i)_t+w(\varphi_i)_x=0$. При умножении $Q_t+F_x=0$ на $\varphi_i$ и интегрировании по частям получаем

$$
\frac{d}{dt}\int_0^L Q_h\varphi_i\,dx
=\int_0^L (F(Q_h)-wQ_h)(\varphi_i)_x\,dx
-\bigl[\varphi_i(F(Q_h)-wQ_h)\bigr]_0^L.
$$

Потоки массы и энергии на стенках нулевые. Для импульса используются внутренние тестовые функции, а в крайних узлах задано $u=0$. Суммирование строк локальной матрицы масс $\frac{\Delta x_i}{6}\begin{pmatrix}2&1\\1&2\end{pmatrix}$ даёт диагональную матрицу. Функция `masses` вычисляет её диагональ $m_i$ как половину суммы длин прилегающих элементов. В `rhs` два узла Гаусса дают средний поток $F-wQ$ по элементу. Он входит в производную $Z_i=m_iQ_i$ со знаком минус слева и плюс справа, поэтому вклады элементов в суммы массы и энергии сокращаются. Давление и удельную внутреннюю энергию восстанавливаем из $Q$.

Координаты $X$ и величины $Z$ обновляются явным методом Рунге — Кутты третьего порядка. На каждой стадии $Q=Z/m(X)$ и поток вычисляются заново. Код проверяет длины элементов, плотность, давление и число Куранта по скорости $|u-w|+\sqrt{\gamma p/\rho}$. Схема рассчитана на гладкое возмущение.

На всех слоях крайние узлы остаются в $0$ и $1$. Минимальная длина элемента составляет $0.004939$, максимальное смещение узла — $0.001692$. Относительные ошибки массы и полной энергии по всем слоям составляют $8.9\cdot10^{-16}$ и $1.2\cdot10^{-15}$. Для постоянного состояния покоя на неравномерной сетке правая часть `rhs` даёт нулевые производные $X$ и $Z$.

На конечном слое после интерполяции разностного решения в узлы ALE максимальные расхождения скорости, давления и плотности составляют $5.2\cdot10^{-5}$, $4.8\cdot10^{-5}$ и $3.8\cdot10^{-5}$ соответственно. Для давления и плотности сравниваются узлы внутри диапазона центров лагранжевых ячеек.

## Запуск

Из корня репозитория перейдите в папку работы и запустите нужный вариант.

```bash
cd AppliedMathematics/laba2
uv run python laba2.py
uv run python compressed.py
uv run python laba2-ale.py
```

В контейнере используйте `python3` с теми же файлами. Для ALE нужны NumPy, Matplotlib и Pillow.

Данные ALE сохраняются в `results/ale/gas.npz`. Массивы `X, U, V, E, P` содержат узловые значения, время хранится в `t`. Графики и анимация показывают поля в физических координатах $x$. Нижняя правая панель графика показывает смещение каждого десятого узла относительно начальной позиции.
