# Лабораторная работа 2. Газовая динамика

Открыть **[laba2.ipynb](laba2.ipynb)**. Код основан на твоём примере из [XYGEF](https://clck.su/XYGEF), ячейка с полностью консервативной схемой и методом Ньютона.

Как в исходной работе: массивы `X, U, V, E, P`, равномерная сетка по времени, прогонка, Ньютон, проверка энергии и графики полей. Данные: L=1, T=0.12, N=200, M=80, γ=1.4, гауссово возмущение давления, неподвижные стенки.

[Графики](results/gas.png) · [Анимация](results/gas.gif). Все временные слои — `results/gas.npz`.

Код без notebook — [laba2.py](laba2.py); запуск из этой папки в контейнере: `python3 laba2.py`.
Оба присланных оригинала сохранены в `../laba1/materials/` и [materials/](materials/README.md).
