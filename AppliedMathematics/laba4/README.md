## Компактные варианты стенки

Все варианты написаны в стиле `compressed.py`: неявная схема, прогонка внутри цикла, без собственных функций.

| [laba4-2.py](laba4-2.py) | Та же четырёхслойная стенка | Робин: −λTₓ = hᵥ(Tпов − Tвозд), Tвозд = −50 °C |

Сводки по вариантам: [1](results/laba4-1/summury.md), [2](results/laba4-2/summury.md), [3](results/laba4-3/summury.md), [4](results/laba4-4/summury.md), [5](results/laba4-5/summury.md), [6](results/laba4-6/summury.md). В каждой — постановка задачи, параметры, метод, стационарное решение, изменение во времени, проверки и вывод.

В вариантах 3–6 пенофола нет, остаётся один слой пенопласта с указанной стороны кирпича. Учебные свойства пенопласта: λ = 0.04 Вт/(м·К), ρ = 30 кг/м³, c = 1400 Дж/(кг·К); кирпича: λ = 0.7 Вт/(м·К), ρ = 1800 кг/м³, c = 840 Дж/(кг·К). Слева во всех вариантах задано 20 °C, начальная температура внутри −50 °C. В вариантах 5 и 6 параметры Робина те же, что в варианте 2: v = 5 м/с, hᵥ = 24.7 Вт/(м²·К).

Для пенофола приняты λ = 0.049 Вт/(м·К), ρ = 40 кг/м³, c = 1950 Дж/(кг·К).
λ и c выбраны по [таблице характеристик Пенофола](https://www.penofol.com/harakteristiki/), плотность — учебное допущение. Пенофол — фольгированный вспененный полиэтилен; свойства конкретной марки из «Арктики» без её паспорта не определены. Здесь учитывается теплопроводность слоя с постоянными свойствами; отражение фольги и воздушная прослойка в модель не включены.

Во втором варианте v = 5 м/с — условный умеренный ветер у поверхности, а не климатическое среднее: населённый пункт и период усреднения не заданы. По [формуле McAdams в EnergyPlus](https://bigladdersoftware.com/epx/docs/24-2/engineering-reference/outside-surface-heat-balance.html#mcadams), hᵥ = 5.7 + 3.8v = 24.7 Вт/(м²·К). Значение `v` меняется в начале файла. Слева в обоих вариантах задана температура поверхности 20 °C; начальная температура внутри −50 °C. Шаг времени 600 с, время 7 суток, 20 отрезков на каждый слой.

Условие Робина дискретизируется как Gпосл(Tпред − Tпов) = hᵥ(Tпов − Tвозд). Температура поверхности исключается из системы; проводимость к воздуху равна `1/(1/G[-1] + 1/h_wind)`. Граничный узел не имеет собственной теплоёмкости, как и в исходном расчёте; баланс проверяется по внутренним контрольным объёмам. Температура наружной поверхности вычисляется на каждом шаге.

Стационарный поток равен 22.866667 Вт/м² в первом варианте и 22.568194 Вт/м² во втором. Добавление пенофола при исходных условиях Дирихле снижает поток на 6.67% относительно 24.5 Вт/м². При Робине добавляется сопротивление теплоотдачи `1/h_wind`, поэтому температура поверхности отличается от температуры воздуха.
