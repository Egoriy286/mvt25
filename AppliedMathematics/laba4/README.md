# Лабораторная работа 4. Теплопроводность

Открыть **[laba4.ipynb](laba4.ipynb)**. Сначала параметры и сетка, затем прогонка, неявная схема, проверка стационарного решения и графики.

Пенопласт — кирпич — пенопласт. Учебные параметры согласованы в чате: толщины 5/25/5 см, λ=0.04/0.7/0.04, ρ=30/1800/30, c=1400/840/1400. Слева 20 °C, справа и в начале внутри −50 °C. Время 7 суток, шаг 600 с, 20 отрезков на слой.

[Температура и потоки](results/heat.png). Стационарный поток 24.5 Вт/м²; температуры стыков −10.625 и −19.375 °C. Через 7 суток решение ещё приближается к стационарному.

Параметры меняются в начале notebook, отдельный конфигурационный файл не требуется.
Код без notebook — [laba4.py](laba4.py); запуск из этой папки в контейнере: `python3 laba4.py`.
