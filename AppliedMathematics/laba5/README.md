## Постановка задачи

Найти температуру \(T(x,t)\) на \(0<x<\ell\), \(0<t\le t_{\max}\):

\[
c\rho T_t=\lambda T_{xx}-vT_x,\qquad T(x,0)=T_0(x),
\]
\[
\lambda T_x(0,t)=\alpha_1[T(0,t)-T_1(t)],\qquad
-\lambda T_x(\ell,t)=\alpha_2[T(\ell,t)-T_2(t)].
\]

Заданы \(c,\rho,\lambda>0\), \(v(x,t)>0\), \(\alpha_1,\alpha_2\ge0\), \(T_0,T_1,T_2\). На фотографии численных данных нет. Для расчёта выбран **учебный пример в условных единицах**: \(c=\rho=\lambda=\ell=v=1\), \(\alpha_1=\alpha_2=2\), \(T_1=20\), \(T_2=T_0=0\), \(t_{\max}=2\). В коде используется постоянный положительный \(v\).

## Разностная схема

\(h=\ell/N\), \(\tau=t_{\max}/M\), \(r=c\rho h^2/(\lambda\tau)\), \(g=vh/\lambda\), \(s_k=\alpha_kh/\lambda\). Для \(y=u^{j+1}\), \(z=u^j\):

\[
r(y_i-z_i)=y_{i+1}-2y_i+y_{i-1}-g(z_i-z_{i-1}),\quad 1\le i<N,
\]
\[
\frac r2(y_0-z_0)=y_1-y_0-s_1(y_0-T_1^{j+1}),
\]
\[
\frac r2(y_N-z_N)=y_{N-1}-y_N-s_2(y_N-T_2^{j+1})-g(z_N-z_{N-1}).
\]

Диффузия неявная, перенос явный с левой разностью. Граничные строки взяты из системы (2) на фото: половинная теплоёмкость, без переноса слева и с полным множителем \(g\) справа. В записи \(\bar\alpha_k=\alpha_k/\lambda\) на доске пропущен множитель \(h\): после нормировки граничной строки требуется \(s_k=\alpha_kh/\lambda\).

Полученная трёхдиагональная система решается прогонкой. Для неотрицательности коэффициентов явной части достаточно \(2v\tau/(c\rho h)\le1\); множитель 2 учитывает правую граничную строку. При \(N=80\), \(M=2000\): \(h=0.0125\), \(\tau=0.001\), \(2\mathrm{CFL}=0.16\). Порядок аппроксимации — \(O(\tau+h)\).

## Проверка и запуск

Проверяются невязки всех строк, пределы температуры и совпадение первого и последнего шагов с `numpy.linalg.solve`. При постоянных данных точное стационарное решение имеет вид \(T_\infty=A+B e^{vx/\lambda}\), где

\[
\begin{pmatrix}\alpha_1&\alpha_1-v\\\alpha_2&(\alpha_2+v)e^{v\ell/\lambda}\end{pmatrix}
\begin{pmatrix}A\\B\end{pmatrix}=
\begin{pmatrix}\alpha_1T_1\\\alpha_2T_2\end{pmatrix}.
\]

Код отдельно сравнивает стационарную сеточную погрешность и оставшееся отклонение по времени. Параметры меняются в начале файла; проверка стационара требует постоянных \(T_1,T_2\) и хотя бы одного положительного \(\alpha_k\).

При \(t=2\) температуры слева, в центре и справа равны **17.167398, 13.531509, 7.583488**. Невязка системы — \(1.42\cdot10^{-14}\), отличие от прямого решения — \(5.33\cdot10^{-15}\). Ошибка сеточного стационара — **0.020168**; оставшееся отклонение по времени от него — **0.030008**.

На сетках \(N=20,40,80,160\) стационарная ошибка равна 0.079450, 0.040131, 0.020168, 0.010109: порядок 0.996. Дополнительно проверена нестационарная задача с \(T_*=e^{x/2-t/4}\), \(T_0=e^{x/2}\), \(T_1=\tfrac34e^{-t/4}\), \(T_2=\tfrac54e^{1/2-t/4}\), \(0\le t\le1\), \(M=25N\): максимальные ошибки 0.004517, 0.002278, 0.001144, 0.000573, порядок 0.997. Постоянное решение сохраняется при \(v=0\) и \(v=1\).
