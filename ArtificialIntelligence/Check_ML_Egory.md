## 5. Accuracy и Recall

```text
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Recall   = TP / (TP + FN)
```

Дано:

```text
TP = 0
TN = 990
FN = 10
FP = 0
```

Расчёт:

```text
Accuracy = 990 / 1000 = 99%
Recall   = 0 / 10 = 0
```

В данном случае `Accuracy` — недостаточно сильное утверждение, потому что `Recall = 0`. Я пересмотрел датасет.

## 7. PyTorch: порядок действий и определения

- `prediction = model(x)` — предсказание модели, прямой проход.
- `loss = criterion(prediction, y)` — ошибка предсказания и целевого признака.
- `loss.backward()` — обратное распространение ошибки; посчитать ошибку и градиент, обратный проход.
- `optimizer.step()` — делает шаг оптимизатора; инициализация/обновление параметров по сохранённым ошибкам; меняем веса.
- `optimizer.zero_grad()` — очистить дерево градиентов, приравнять его к нулю.

## 8. JAX

### `jax.grad`

`jax.grad` — градиент от функции.

```python
def f(x):
    return x ** 2

jax.grad(f, argnums=0)  # вернёт функцию, соответствующую 2 * x
```

Короче: делает цепь градиента и вернёт функцию от параметра; автодифференцирование.

### `jax.jit`

`jax.jit` — компиляция, создание графа вычислений, перевод функции NumPy в XLA-код через цепное правило. Запускает один раз, после чего функция становится высокопроизводительным машинным кодом.

### `jax.vmap`

`jax.vmap` — автоматическая векторизация функции; иммутабельный вектор, очень производительная операция.

### Пример

```python
def loss(w, X, y):
    prediction = X @ w
    return ((prediction - y) ** 2).mean()

# Организовал бы так: w является матрицей.
# Ускоряем всё с помощью JIT:
loss_grad_fn = jax.jit(jax.grad(loss, argnums=0))

grads = loss_grad_fn(w, X, y)
learning_rate = 1e-3
w = w - learning_rate * grads
```

## 10. NLP / Transformer

- **Токен** — единица информации, представленная в виде числа.
- **Embedding** — вектор, представленный в пространстве терминов и понятий. Обычно используется для NLP. Бывает статический и предобученный. Между ними можно сравнить с помощью косинусного приближения и добавить в пространство новое понятие.
- **Self-attention** — относится к статье “Attention Is All You Need” (Google LLC). В ходе исследования в области машинного перевода был выдвинут новый подход для учёта контекста и соединения понятий токенов в контекстном окне. Attention представляется в виде `Key`, `Value`, `Query`; дальше в ходе преобразований и матрично-векторных умножений получается проекция на данное пространство контекста, и подбирается с помощью `softmax`.
- **Нужна ли модели информация о порядке токенов?** Я не согласился. Токены могут быть представлены в любом порядке, но для текстовых данных особенно важен порядок — от этого зависит контекст, семантическая и смысловая нагрузка текста. Обычно сравнивается порядок слов с помощью косинусного приближения.
- **Предсказание при обучении** — модель предсказывает следующий токен. Берётся предсказание, оно идёт в поле представления `embeddings`, оттуда по косинусному приближению подбираются подходящие токены; берём более подходящий. Обычно выступает отдельный декодер, чтобы предсказание работало отлично.
- Спасибо, но формулы у меня в голове не остаются красивым образом; смысловые понятия и воспоминания остаются.

## 12. Агентные системы

### Инструменты

- векторная база данных;
- сама модель LLM;
- обработчик текстов;
- сжатие контекста;
- скрипт для загрузки документных данных;
- непрерывный pipeline research для LLM;
- доступ в интернет через `MCP`;
- `MCP` — универсальный агентный API для управления сервисами: например, почта, поисковая система, сервис поставщика.

### Последовательность действий

Зависит от задачи.

- Если поиск документов — через `embedding` сразу можно найти релевантные данные.
- Для агентного режима отлично работает: запрос → создание `MCP`-вызова → поиск в интернете → поиск релевантных источников. Вроде так работают `Perplexity` и `ChatGPT`.

- **RAG** — подбор релевантных ссылок / `embedding` из `VectorDB`.
