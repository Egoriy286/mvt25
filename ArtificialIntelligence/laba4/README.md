# Лабораторная № 4. Цены квартир в Якутске

Нейросеть предсказывает цену квартиры по характеристикам жилья и района. На 79 тестовых объявлениях средняя абсолютная ошибка модели составила 1,110 млн руб. У прогноза медианой ошибка составила 2,831 млн руб. [Ноутбук с расчётом](laba4.ipynb)

Из корня репозитория откройте ноутбук в JupyterLab и выполните **Run All**.

```bash
uv run --locked --package laba4 jupyter lab ArtificialIntelligence/laba4/laba4.ipynb
```
