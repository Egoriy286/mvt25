# Практическая работа 4. DOLFIN и MPI

В `laba4.py` решается задача Пуассона −Δu = 1 на единичном квадрате с условием u = 0 на границе. Сетка 320×320 содержит 103041 вершину. Используются элементы P1, метод сопряжённых градиентов и предобуславливатель Hypre AMG. Замер охватывает построение сетки, сборку и решение системы. [Код расчёта](laba4.py)

Откройте терминал контейнера FEniCS Legacy и запустите расчёт на одном процессе. [Инструкция по запуску контейнера](../INSTALL.md#запуск-работ-с-fenics-legacy)

```bash
cd /workspace/fenics-legacy/ParallelComputing/laba4
mpirun -n 1 python3 laba4.py
```

При запуске на нескольких процессах программа зависает после вывода времени. Запись распределённого поля в `solution.pvd` вызывается только на процессе 0, хотя в записи должны участвовать все процессы. `run.py` очищает `results/times.csv` перед серией, а `laba4.py` выводит замеры только в терминал. Результаты предыдущих запусков сохранены в репозитории. [Таблица](results/table.csv) · [График](results/time.png) · [Решение](results/solution.png)

Контейнер имеет лимит 4 CPU. При замерах на 12–16 MPI-процессах они делили эти ресурсы. [Исходное задание](Практика%204.pdf)
