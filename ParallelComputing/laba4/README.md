# Практическая работа 4. DOLFIN и MPI

Основной код — **[laba4.py](laba4.py)**. Как в прежних MPI-работах: параметры, задача, замер времени, вывод результата на процессе 0.

Решается −Δu=1 на квадрате 1×1, u=0 на границе. Сетка 320×320: 103041 вершина. P1, CG + Hypre AMG. Время включает сетку, сборку и решение; компиляция прогрета заранее, файловый вывод исключён.

Один запуск в терминале контейнера:

```bash
cd /workspace/fenics-legacy/ParallelComputing/laba4
mpirun -n 4 python3 laba4.py
```

Все замеры для 1/2/4/6/8/12/16 процессов, по три раза:

```bash
python3 run.py
```

`run.py` заново записывает таблицу `results/times.csv`, затем считает медианы в `results/table.csv`. График — `results/time.png`. Решение — `results/solution.pvd` и `results/solution.png`.

Контейнер имеет лимит 4 CPU: запуски на 12–16 процессах не означают работу на 12–16 выделенных ядрах. Ускорение оценивается для этой среды. [Исходное задание](materials/README.md).
