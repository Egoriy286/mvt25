# Параллельные вычисления

Практические работы по MPI на C, C++ и Python. Для работ 4, 5 и 7 используется FEniCS Legacy (DOLFIN).

- [Установка MPI и запуск работ](INSTALL.md)
- [Лекция по MPI](2.%20MPI.%20Подробнее.pdf)

## Сборка и запуск с MPI

Из корня репозитория выполните `cd ParallelComputing`. Флаг `-n` задаёт число MPI-процессов.

| Работа | Сборка | Запуск |
|---|---|---|
| [1. Передача сообщений](laba1/) | `mpicc laba1/laba1.c -o laba1/laba1` | `mpirun -n 4 ./laba1/laba1` |
| [2. Сумма элементов массива](laba2/) | `mpicc laba2/laba2.c -o laba2/laba2` | `mpirun -n 4 ./laba2/laba2 8` |
| [3. Умножение матрицы на вектор](laba3/) | `mpicc laba3/laba3.c -o laba3/laba3` | `mpirun -n 4 ./laba3/laba3 8` |
| [3. Вариант с равными блоками](laba3/laba3-1.c) | `mpicc laba3/laba3-1.c -o laba3/laba3-1` | `mpirun -n 4 ./laba3/laba3-1 8` |
| [6. Метод Якоби](laba6/README.md) | `mpicxx -x c++ laba6/laba6.c -o laba6/laba6` | `(cd laba6 && mpirun -n 4 ./laba6 8)` |
| [8. Умножение матриц](laba8/README.md) | `mpicc -std=c11 -O2 laba8/laba8.c -o laba8/laba8` | `(cd laba8 && mpirun -n 4 ./laba8 5)` |

В работе 2 аргумент `8` задаёт размер массива, а в работе 3 — порядок квадратной матрицы. В работе 8 аргумент `5` задаёт размер матриц. Матрицы сохраняются в `A.txt`, `B.txt` и `C.txt`. [Проверка работы 8](laba8/README.md#проверка-результата)

В работе 6 порядок матрицы должен быть кратен числу процессов. Запуск перезаписывает `A.txt`, `b.txt` и `x.txt`. Для проверки результата по NumPy запустите расчёт на одном процессе. [Проверка работы 6](laba6/README.md#проверка-решения)

## Работы с FEniCS Legacy

Команды запускайте из папки соответствующей работы в [контейнере FEniCS Legacy](../FENICS.md).

| Работа | Один расчёт | Серия замеров |
|---|---|---|
| [4. Задача Пуассона на квадрате](laba4/README.md) | `mpirun -n 1 python3 laba4.py` | [Сохранённые замеры](laba4/results/table.csv) |
| [5. Методы Крылова и предобуславливатели](laba5/) | `mpirun -n 4 python3 solve.py --arg1 cg --arg2 none` | `python3 runner.py`, затем `python3 evaluate.py` |
| [7. Одномерная задача Пуассона. MPI и FEniCS](laba7/README.md) | [Команды для C и DOLFIN](laba7/README.md) | `python3 run.py` |

В текущей версии работы 4 запуск на нескольких процессах зависает при записи поля, а `run.py` очищает `results/times.csv` перед серией. Для просмотра замеров используйте сохранённую таблицу.

Серия в работе 5 перебирает 120 комбинаций и записывает замеры в `data.npz`. Скрипт `evaluate.py` формирует `data.csv`. Доступность методов и предобуславливателей зависит от PETSc и числа процессов.
