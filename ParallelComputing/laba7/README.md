# Практическая работа 7. Одномерная задача Пуассона

Решаем $-ku''=1$ на $(0,1)$ при $u(0)=u(1)=0$ и $k=0.1$. [Задание](<Практика 7.pdf>).

## Разностная схема

Разбиваем отрезок на $N$ частей с шагом $h=1/N$. Для внутренних узлов $x_i=ih$ получаем

$$
\frac{k}{h^2}(-u_{i-1}+2u_i-u_{i+1})=1,\qquad i=1,\ldots,N-1.
$$

Каждый процесс собирает свои строки трёхдиагональной матрицы. Если строки делятся с остатком, первые процессы получают по одной дополнительной строке. На каждой итерации процессы обмениваются крайними значениями с соседями. Как в работе 6, метод Якоби обновляет решение по значениям с предыдущей итерации. [Код МКР](laba7.c) · [Работа 6](../laba6/README.md)

$$
u_i^{(m+1)}=\tfrac12\left(u_{i-1}^{(m)}+u_{i+1}^{(m)}+h^2/k\right).
$$

Критерий остановки — относительная невязка $\|Au-b\|_2/\|b\|_2\le 10^{-10}$, проверяемая каждые 50 итераций. Предел — 2 млн итераций. Процесс 0 собирает узловые значения, если задан путь к CSV.

## Сравнение с МКЭ

В [solve.py](solve.py) DOLFIN собирает слабую форму $\int_0^1 ku'v'\,dx=\int_0^1 v\,dx$ на той же сетке с линейными элементами P1. Систему решает MUMPS. Разностное решение интерполируется в то же пространство перед вычислением относительной погрешности.

$$
e_{L^2}=\frac{\|u_{\text{МКР}}-u_{\text{МКЭ}}\|_{L^2(0,1)}}{\|u_{\text{МКЭ}}\|_{L^2(0,1)}}.
$$

На равномерной сетке с постоянной правой частью уравнения МКЭ для внутренних узлов совпадают с разностными уравнениями после деления на $h$. Поэтому величину расхождения определяют допуск Якоби и округление. Отдельно МКР проверяется в узлах по точной формуле $u(x)=x(1-x)/(2k)$.

## Запуск

Один расчёт на четырёх процессах в терминале [FEniCS Legacy](../../FENICS.md).

```bash
cd /workspace/fenics-legacy/ParallelComputing/laba7
mpicc -std=c11 -O3 laba7.c -lm -o /tmp/laba7
mpirun -n 4 /tmp/laba7 128 /tmp/laba7.csv
mpirun -n 4 python3 solve.py 128 /tmp/laba7.csv
```

Серия замеров собирает программу во временной папке. По умолчанию используется 128 ячеек и по три запуска на 1, 2 и 4 процессах.

```bash
python3 run.py
python3 run.py --cells 64 --processes 1 2 3 4 --repeats 3
```

Число процессов должно быть меньше $N$. Для расчёта ускорения `run.py` всегда включает один процесс.

## Полученные замеры

FEniCS Legacy, Apple M4, ARM64-контейнер с лимитом 4 CPU. Для каждого метода берётся медиана трёх замеров и считается ускорение $S_p=T_1/T_p$. Для МКР измеряется сборка строк и решение, для МКЭ — построение сетки, сборка и решение после прогрева форм. Время запуска MPI, файловый вывод и вычисление ошибок в замер не входят.

| Процессы | МКР, с | $S_p$ МКР | МКЭ, с | $S_p$ МКЭ |
|---:|---:|---:|---:|---:|
| 1 | 0.004286 | 1.000 | 0.001948 | 1.000 |
| 2 | 0.037215 | 0.115 | 0.002898 | 0.672 |
| 4 | 0.043970 | 0.097 | 0.003645 | 0.534 |

Для каждого числа процессов метод Якоби сошёлся за 76 150 итераций. Относительная невязка составила $9.882\cdot10^{-11}$, относительная $L^2$-ошибка к МКЭ — $1.091\cdot10^{-10}$, максимальная ошибка МКР в узлах к точному решению — $1.409\cdot10^{-10}$. При 127 внутренних узлах вычислений на процесс мало, поэтому обмены увеличили время работы обоих методов при 2 и 4 процессах.
