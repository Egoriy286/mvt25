# Лабораторная работа № 2

## Описание

Реализовать параллельное сложение массива с использованием MPI.
Массив генерируется случайными числами от 0 до 20. На ввод
подается n – размер массива. MPI_Reduce использовать нельзя.

## Компиляция и запуск

Для сборки и запуска с использованием MPI:

```bash
mpicc laba2.c -o laba2
mpirun -np 4 laba2
```
