# Лабораторная работа № 2

## Описание

Программа суммирует случайный массив с помощью `MPI_Scatterv` и `MPI_Gather`. Размер массива передаётся первым аргументом. [Условие работы](Практика%202.pdf)

## Компиляция и запуск

Из папки `ParallelComputing/laba2` соберите программу и запустите её на четырёх процессах с массивом из восьми элементов.

```bash
mpicc laba2.c -o laba2
mpirun -n 4 ./laba2 8
```
