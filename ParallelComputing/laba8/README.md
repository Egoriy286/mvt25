# Практическая работа 8. Умножение матриц

Программа читает размер `N` из аргумента командной строки и заполняет две матрицы `N × N` случайными целыми числами от 0 до 20. Процесс 0 распределяет строки `A` через `MPI_Scatterv` и рассылает `B` целиком через `MPI_Bcast`. Каждый процесс вычисляет свой блок строк `C = A × B`. `MPI_Gatherv` собирает блоки на процессе 0, даже если `N` не кратно числу процессов. [Задание](Практика%208.pdf) · [Код](laba8.c)

## Сборка и запуск

Из корня репозитория перейдите в папку работы и соберите программу. [Установка MPI](../INSTALL.md)

```bash
cd ParallelComputing/laba8
mpicc -std=c11 -O2 laba8.c -o laba8
mpirun -n 4 ./laba8 5
```

В этой команде `4` задаёт число MPI-процессов, а `5` — размер матриц.

Процесс 0 записывает матрицы в текущую папку. В TXT каждая строка матрицы занимает одну строку файла, числа разделены пробелами. Новый запуск перезаписывает файлы. [A.txt](A.txt) · [B.txt](B.txt) · [C.txt](C.txt)

## Проверка результата

Скрипт загружает три файла, независимо вычисляет `A @ B` через NumPy и сравнивает с `C`. Для верного результата максимальная разность равна нулю. [Скрипт проверки](eval.py)

```bash
uv run python eval.py
```
